# Naming — strategy-led generation and clearance triage

Treat naming as a strategic, linguistic and legal-risk decision. Establish enough of the brand job and position to know what the name must do before generating candidates.

## 1. Define the naming job

Specify only the constraints that materially affect the decision: what the name should signal or deliberately leave open; markets and languages; how much category legibility is needed now; future scope tolerance; architecture or endorsement relationship; phonetic constraints; relevant legal classes when triage is needed; portfolio patterns to avoid or share.

## 2. Diverge by mechanism

Generate materially different naming lineages (descriptive, suggestive, metaphorical, real word, compound, coined, morphological, initials where context genuinely supports them). Labels help compare candidates; they are not rankings, and every cell does not need a candidate.

## 3. Test language and speech

For declared markets, check pronunciation, spelling, spoken transfer, ambiguity, unintended slang or connotation, cross-language risk and similarity to confusing category or portfolio names. Model judgment is triage; require native review when material uncertainty remains.

## 4. Run clearance triage when consequence requires it

Use current authoritative sources for procedures and current search systems for marks, domains and handles; search confusingly similar marks where feasible, not only exact strings. Report one of: no apparent collision found in triage; apparent collision or risk; uncertain, specialist review needed. Never describe model or web triage as definitive legal clearance.

## 5. Converge

Evaluate survivors on fit to the naming job and position, distinctiveness in context, memorability and usability, scope flexibility, language robustness, legal and domain risk, and creative potential inside the identity system. Recommend a preferred name; present alternatives only when they materially improve the decision or the user asks.

## 6. Persist only durable naming state

When naming belongs in the contract: the selected name, a concise naming job when it prevents drift, meaningful exclusions, markets that materially constrain use, and dated clearance and linguistic triage with any unresolved specialist dependency. Not the candidate list. For a market-facing new name, an unresolved collision or missing high-consequence legal review stays an explicit dependency in the delivery report.
